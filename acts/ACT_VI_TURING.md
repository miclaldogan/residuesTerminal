# 🧠 ACT VI SPECIFICATION: TURING (1936 / 1950) — UNIVERSALITY

## 1. THE ARCHITECTURAL TIMELINE & THE GHOST JURY

When Act VI initializes, `GlobalStateContext.current_act = Act::Turing1936_1950`. There is no portrait sheet drawn on top; instead, the cursor focus is locked onto the narrator himself. The Ghost Jury is now fully assembled: Jacquard, Babbage, Lovelace, Boole, and Shannon occupy the terminal corner coordinate buffers. They do not speak; their text blocks are hard-rendered into the layout, staring directly into the user’s camera view as a silent, corporate jury.

## 2. THE THREE-PHASE EPIC LAYER MODEL (THE MACRO TEMPO)

To extend the act into a comprehensive psychological simulation, the gameplay matrix transitions through three chronological and technical phases separated by violent terminal page-flips.

### Phase 1: Pure Logic & The B-Machine (1936–1940) — Clarity

* **Visual Skin:** Pristine white character strings; ink buffers flow completely clean; the candlelight radiance updates smoothly at maximum contrast.
* **The Abstract Tape Puzzle (1936):** The user builds a fundamental Universal Turing Machine—designing a dynamic state transition table over an unbounded horizontal text strip (The Tape). The puzzle requires the player to write logic rules that accept a description of prior acts (Jacquard's cards, Babbage's differences, Lovelace's loops), proving that one single abstract architecture can imitate every prior machine.
* **The Bombe Vector (1940):** The tape transitions into a simulation of the Bombe. Instead of solving simple cryptographic riddles, the user manages rotor synchronization using the state table. The logic runs with absolute technical clarity.
* **Turing's Voice (Confident, Clinical):**
  ```text
  [TURING VIA MIND_LOG]: "Just follow the symbols. I broke Enigma's millions of rotors with logic cruder than this. Set the rules; let the machine imitate the universe."
  ```

### Phase 2: The Interrogation & The Tremor (1950) — Betrayal

* **Visual Skin:** Text rows degrade into straw-colored, coffee-stained formats. The Stilboestrol pill boxes quietly cluster on the right side of the screen grid. The high-pass radio static audio stream introduces military telegraph (morse) frequencies.
* **The Imitation Game Mechanic:** The workspace transitions into a text-interrogation terminal. The user inputs analytical questions to identify the human from the machine backend behind the wall.
* **The Police Inversion:** As the questions iterate, the script variables subtly desynchronize. The identity testing questions blur, morphing explicitly into the historic criminal interrogation records Turing faced during his 1952 trial. The user experiences a mathematical validation routine turning into an administrative weapon of social exclusion.
* **The Input Tremor Bug:** The core system injects microsecond keyboard repeat buffers. Tapping a command string once accidentally executes double character repetitions (`shannon_initial()` splits into `shshannon__iinitiall()`), forcing the user to constantly backtrack to clear input noise.

### Phase 3: Morphogenesis & System Collapse (1951) — Poison

* **Visual Skin:** Total visual erosion. The terminal palette color coordinates drop to low-contrast, muddy charcoal grays (`#2A2A2A`). The metronome switches into an unstable, arrhythmic sub-bass heartbeat pulse. The meşum apple graphic mutates into its heavily bitten state.
* **The Unwinnable Code Loop:** The user attempts to map complex differential equation models (morphogenesis arrays) on the tape.
* **The Forced Interpreter Failure:** Even if the input matrix code is mathematically infallible, the computation fails automatically upon execution (`turing_step()` overrides values). The bits on the tape flip corruptively without the player's doing because the compiler—Turing’s eroding biological neural state—can no longer map the transition instructions.
* **Turing's Inner Monologue:**
  ```text
  [TURING VIA MIND_LOG]: "No — the code is right. The logic is perfect. But I cannot read it. The chemicals erase the thoughts from the tape. A machine's mind does not get confused. Mine... blurs."
  ```

## 3. THE WILLPOWER EXIT (THE CORE RELEASE)

The player cannot bypass Phase 3 by thinking faster or optimizing the code layers. The puzzle terminates the mathematical phase to force a localized crisis of sheer intent.

As the candle cells approach zero, the user must navigate past the blinding vision blur, look past the horizontal row stuttering, ignore the double-clicks, and execute a hard manual `HALT` instruction through raw, persistent keystrokes. The Universal Machine completes its final execution cycle for a brief, crisp tick.
